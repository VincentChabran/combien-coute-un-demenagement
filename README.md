# 1 239,56 € : le coût de revient officiel d'un déménagement de 27 m³

**On a compté.** Pas un conseil, pas une astuce — un chiffre, sa décomposition, sa source.

Un coût de revient, c'est la base sur laquelle l'entreprise construit son prix — avant marge, TVA
et options. Ce n'est pas ce qu'un client paie, c'est ce qu'il en coûte réellement à l'entreprise.

## La décomposition (CNR)

Déménagement particulier de 27 m³, 100 km, 1 jour (1 porteur + 3 déménageurs) :

| Poste | Montant | Part |
|---|---|---|
| Main d'œuvre | 1 049,07 € | 84,6 % |
| Véhicule | 119,29 € | 9,6 % |
| Kilomètres | 71,20 € | 5,8 % |
| **Total** | **1 239,56 €** | 100 % |

En hausse de **+24,6 %** depuis 2019 (Tableau 4, CNR).

## Les postes annexes qu'on oublie

- **Réexpédition du courrier, 1 an** : 87 €. Tarif national La Poste, souscrit à part.
- **Mise en service électricité** : 1,45 € avec compteur Linky, jusqu'à 26,52 € sans, sur un
  raccordement existant.
- **Congé légal pour déménager** : 0 €. Contrairement au mariage ou à une naissance, le Code du
  travail ne prévoit aucun congé pour déménager — ça dépend uniquement de la convention collective
  ou d'un accord d'entreprise, que l'employeur peut refuser.
